# contexto-solver

Солвер для [контекстно.рф](https://t.me/contextno_bot), угадывающий секретное слово за 2-3 хода методом точной триангуляции в векторном пространстве word2vec.

## Принцип работы

### Устройство игры

Контекстно использует дистрибутивную семантику: каждое слово словаря представлено вектором в **R^300**, обученным методом word2vec на большом русскоязычном корпусе. Близость двух слов *u* и *v* определяется косинусным сходством нормированных векторов:

$$\text{sim}(u, v) = \frac{\vec{u} \cdot \vec{v}}{|\vec{u}||\vec{v}|}$$

Когда игрок вводит слово *G* (guess), игра возвращает его **ранг** относительно секрета *C*:

$$\text{rank}(G \mid C) = |\{V \in \mathcal{V} : \text{sim}(V, C) \geq \text{sim}(G, C)\}|$$

То есть ранг - это количество слов словаря *V*, которые похожи на секрет не меньше чем угадка. Ранг 1 означает что *G = C*.

### Ключевое наблюдение

Уравнение `rank(G | C) = R` задаёт **сферическую оболочку** в **R^300** вокруг неизвестного секрета *C*: множество всех слов словаря, которые находятся от *C* на косинусном расстоянии, соответствующем ровно *R*-му месту в ранжировании. Геометрически это граница шара с центром в *C* и "радиусом" `sim(G, C)`.

Зная вектор *G* (из локальной копии модели) и наблюдаемый ранг *R*, можно **точно вычислить** множество кандидатов:

$$\mathcal{C}(G, R) = \{W \in \mathcal{V} : |\text{rank}(G \mid W) - R| \leq \varepsilon\}$$

После двух независимых угадок *G1*, *G2* с рангами *R1*, *R2* пересечение:

$$\mathcal{C}(G_1, R_1) \cap \mathcal{C}(G_2, R_2)$$

как правило содержит ровно одно слово -- секрет. Это прямой аналог GPS-триангуляции: два спутника с известными расстояниями однозначно определяют точку в пространстве.

### Вычисление кандидатов

Наивная проверка каждого слова *W* требует O(N^2 * d) операций. Реализуем через батчевое матричное умножение:

```
V_mat  : (N, d)   -- нормированная матрица всего словаря
C_mat  : (k, d)   -- матрица k кандидатов
G_vec  : (d,)     -- вектор угадки

sims   = V_mat @ C_mat.T        # (N, k) -- сходство каждого слова с каждым кандидатом
sim_g  = C_mat @ G_vec           # (k,)  -- сходство угадки с каждым кандидатом
ranks  = (sims >= sim_g).sum(0)  # (k,)  -- ранг угадки от каждого кандидата
```

Одна матричная операция даёт точный ранг для всех *k* кандидатов одновременно. С OpenBLAS на батчах по 2000 слов это занимает ~1 секунду для полного словаря из 20 915 слов.

### Оптимизация: предфильтр

Для первой угадки pool = весь словарь (~21k слов). Вместо полного перебора используем предфильтр: если `rank(G | C) = R`, то *C* должен находиться среди *4R* ближайших соседей *G* (с учётом асимметрии рангов, когда `rank(A | B) != rank(B | A)`). При *R* < 5000 это сокращает пул и ускоряет поиск. При *R* >= 5000 предфильтр пропускается и используется полный пул.

### Систематическое смещение рангов

Игровой словарь незначительно отличается от нашего (~5-7 слов), из-за чего ранги в игре систематически выше локальных:

$$\text{rank}_{\text{game}}(G \mid C) = \text{rank}_{\text{local}}(G \mid C) + \delta, \quad \delta \approx 5$$

Компенсируется допуском ε = 10 в фильтре кандидатов.

### Восстановление при пустом пересечении

Если пересечение пусто (из-за краевых случаев смещения), солвер пересобирает кандидатов с нуля, обрабатывая все угадки в порядке возрастания ранга (от наиболее специфичных к наименее) с постепенно расширяющимся допуском ε, 2ε, 3ε.

## Установка

```bash
yay -S python-gensim python-numpy openblas
```

Модель tayga (~500 MB) положить в `model/model.bin`. Модель доступна на [RusVectores](https://rusvectores.org/ru/models/) или аналогах.

Алиас fish:

```fish
function contexto
    env LD_PRELOAD=/usr/lib/libopenblas.so python3 ~/projects/contexto-solver/kontextno_solver.py $argv
end
```

`LD_PRELOAD` обязателен: без него numpy использует reference BLAS, что замедляет матричное умножение в ~60 раз.

## Использование

```
contexto
```

```
ранг                    -- засчитать предложенное слово
слово ранг              -- засчитать своё слово
сл1 р1 сл2 р2 ...       -- несколько пар сразу
слово ?                 -- слово не в игре
?                       -- показать кандидатов
n                       -- новая игра
q                       -- выход
```
